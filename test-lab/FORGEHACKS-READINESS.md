## Fit

Sentra helps students and everyday users examine suspicious messages and links, identify scam indicators, verify uncertainty and choose safer next actions. The released track asks for AI-powered recognition, prevention, verification or response to scams, impersonation and modern/AI-enabled fraud. Message and URL analysis fits this problem; repository pentesting alone would not demonstrate the whole user problem.

## Demonstration gates

1. Show a normal message and a safety warning without false credential alarms.
2. Show an urgent OTP/password theft request and explain each evidence signal.
3. Show a harmless first link followed by a deceptive second link.
4. Show feed failure as limited coverage, never as proof of safety.
5. Run a real model-backed review with a provider account. Local deterministic agents alone do not establish trained AI/ML use. Keep actual outputs and explain where the reviewer disagrees.
6. Show consent before provider sharing, default non-persistence and clearing of stale cases.
7. Explicitly distinguish working message/URL checks from planned media/identity/full app scanning.

## Submission checklist

- Public GitHub code and clear README.
- Public 2–4 minute demo video showing the problem and working product.
- AI + Cybersecurity track selected.
- Written problem, target users, technical approach and practical impact.
- Deployment link plus genuine screenshots/architecture.
- All actual team members listed; teams may have 1–4 students.
- Identify additions made during the October 3–10 build period; attribute upstream libraries.

Do not claim a guaranteed win, tested live models without evidence, completed Strix scanning, or functionality shown only as a mockup. Judges score impact, technical/AI quality, innovation, completeness and communication.
